What this does and does not test

  • Tests: H.264 negotiation, loopback transport, jitter buffer, receive/decode statistics, frame pacing and canvas presentation for 10 s.
  • Does not test: a real network path, packet loss, congestion, TURN, or adaptive bitrate. Loopback is lossless and local.
  • It uses the same source clip as the WebCodecs player so the decode target is equivalent.
  • It does not request camera, microphone, location or vehicle permissions.
